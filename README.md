🎵 Virtual Mbira (Mbira Dzavadzimu Simulator)

A browser-based virtual mbira built with p5.js and p5.sound, inspired by the traditional Mbira Dzavadzimu (Nyamaropa style) from Zimbabwe.
Users can interact with tapered metal keys, hear individual notes, and explore mbira-inspired layouts and tunings.


✨ Features

  🎶 Clickable mbira keys that produce sound

  🔩 Tapered metal key design (realistic mbira shape)

  🪵 Wooden soundboard with pressure bars

  🎼 Multiple rows of keys (left, center, right)

  🔊 Real-time audio synthesis using p5.sound

  🧠 Object-oriented design for easy extension
  

🛠️ Built With

- JavaScript

- p5.js

- p5.sound.js

- HTML / CSS
